# EchoGuard – Next-Gen Privacy & Cybersecurity Web App

EchoGuard provides a cutting-edge privacy and cybersecurity dashboard: real-time exposure tracking, privacy action plan, dark web monitoring, social graph risk mapping, and more—all powered by AI.

## Features

- **Real-Time Exposure Dashboard:** View your online risk and receive real-time alerts.
- **AI Action Plan:** Interactive checklist for privacy improvements with progress/streaks.
- **Digital Twin Scanner:** Detect digital impersonations and AI-cloned content.
- **Third-Party App Monitor:** Audit and manage connected apps/permissions.
- **Dark Web Leak Monitor:** Scan for leaked data and take mitigation steps.
- **Social Graph Risk Map:** Visualize contact/web risk with interactive D3-powered maps.
- **Badge System:** Earn achievements for good privacy hygiene.

## Getting Started

In the project directory, run:

### `npm start`

Runs the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run build`

Builds the app for production to the build folder.

## Configuration Note

The project includes visual editing plugins required for the editor. **DO NOT** remove the "babel" section in `package.json`—critical for editor integration.

## Customization

Colors, surfaces, and typography can be tuned in `src/App.css`. The UI uses a modular, responsive layout, and pure HTML/CSS components (no major UI framework).
